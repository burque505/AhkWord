# Imágenes

- **Insertar > Imagen** inserta una imagen desde un archivo (PNG, JPEG o GIF), y pide su **texto alternativo**: la descripción que leen los lectores de pantalla, y que se muestra cuando el mouse se detiene sobre la imagen. También puede soltar un archivo de imagen sobre el documento.
- Arrastre una esquina de una imagen para cambiar su tamaño.
- Clic derecho en una imagen > **Texto alternativo...** para cambiar su descripción.
- **Insertar > Miniatura vinculada** pone en la página una imagen pequeña con un vínculo al archivo de la imagen de tamaño completo: útil para imágenes grandes en documentos pensados para leerse en un navegador.

El texto alternativo se conserva en RTF (y a través de él en Word y LibreOffice). Cuando se guarda un archivo HTML o Markdown, sus imágenes se escriben como archivos en una carpeta junto a él (`document_images\image1.png` ...) y el archivo se refiere a ellas; Guardar como > **HTML, imágenes dentro (un solo archivo)** lo conserva todo en un solo archivo.
